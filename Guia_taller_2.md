Project Scoping

En este momento, teniendo en cuenta el acercamiento que has tenido con la organización seleccionada en el módulo anterior, con tu equipo de trabajo elaborarán los planes individuales para el desarrollo y cumplimiento del proyecto decidido para el cierre de brechas en la organización.

Para el desarrollo de los planes individuales, tienen a su disposición esta guía de trabajo en la que encontrarán las instrucciones o elementos que debe tener cada uno de los planes:

Utilizando como base en la idea de proyecto seleccionado en la unidad uno, realice cada uno de los siguientes planes para concretarlo:

- 1. Descripción del contexto donde se desarrollará el proyecto.
- 2. Alcance y limitaciones. Utilice de guía el formulario “DS Project scoping worksheet” que se anexa
- 3. El Plan de presupuesto y recursos del proyecto
- 4. Realizar un desglose de actividades y construir el cronograma
